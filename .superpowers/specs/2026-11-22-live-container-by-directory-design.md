# -L: ディレクトリからライブコンテナを見つける

## 目的

`dozo -LI alpine` で作業を始めたら、そのあとは同じリポジトリ（ディレクトリ）の
どこからでも `dozo -L` だけでそのコンテナにつながるようにする。
あわせて、別の場所にある同じ名前のディレクトリでコンテナを取り違える問題を防ぐ。

## 今の動作（確認済み）

- `-I` なしの `dozo -L` は、名前が `dozo.<dir>` になって見つからず、
  「Docker image must be specified with -I option」で終わる。
- コンテナ名は `<イメージ名の最後の部分>.<マウントするディレクトリの最後の部分>`。
  `a/proj` で `dozo -LI alpine` を始めたあと、`b/proj` で `dozo -LI alpine` とすると、
  `a/proj` をマウントした `alpine.proj` につながる。知らせは出ない。

## 決まったこと

- `-L` でコンテナを作るとき、`--label dozo.mount=<マウントするディレクトリ>` を付ける。
  値はコンテナ名に使うのと同じ `${mount_dir:-$cwd}`（git の中では git のトップ）。
  同じリポジトリなら、どのサブディレクトリからでも同じ値になる。
  - サブモジュールは親リポジトリと同じ、git worktree は作業ツリーごとに別、
    `-W` は今のディレクトリ、`-H` はホーム（今のマウントの決め方のまま）。
- `-L` で、イメージが決まっていない（`-I` も `-D` も `.dozorc` での指定もない）
  かつ `-N` もないとき:
  - `dozo.mount` がこのディレクトリのコンテナを探す。
  - 1 つならそれを使う（起動・exec・attach は今の既存コンテナの処理どおり）。
  - 複数あれば、その名前を並べて `-I` か `-N` で選ぶよう求めて終了する。
  - なければ、今と同じエラー。
- `-K` も同じように、イメージが決まっていなければこのディレクトリのコンテナを探して消す。
- `-I` から名前を作ったとき（`-N` なし）、見つかったコンテナに `dozo.mount` ラベルがあり、
  それが今のディレクトリと違えば、**使わずにエラーで終了する**。別のディレクトリを
  マウントしたコンテナでコマンドを実行してしまうため。メッセージで `-N` で別の名前を
  付けるよう案内する。（設計者の判断: 知らせだけでは、違うファイルに対して
  コマンドが動いてしまう）
  - `-N` で名前を指定したときは、利用者が意図して共有していると考え、確かめない。
  - ラベルのない（この変更より前に作った）コンテナは確かめない。
- ラベルを付けるだけなので、今あるコンテナもこれまでどおり使える。ただし `-I` なしで
  見つけられるのは、ラベルの付いたコンテナ（`-K` で一度作り直したもの）だけ。

## 検討した方法

- ディレクトリごとに最後に使ったイメージを `~/.local/state/dozo/` に記録する:
  記録が実際のコンテナとずれることがあり、取り違えも防げないので不採用。
- `./.dozorc` に `-I` を自動で書き足す: 利用者のファイルを書き換え、git の変更も
  生むので不採用。

## 前提・制約

- `-L` を使わないとき、および `-I` を指定した普段の `-L` の動作は変えない
  （取り違えのエラーを除く）。問い合わせは既存コンテナがあるときの
  `docker inspect` 1 回だけ増える。
- dryrun でも、探すための問い合わせ（`docker ps`, `docker inspect`）は実際に行う
  （読むだけのため）。

## 実装者に任せる点

- ラベルの探し方（`docker ps -a --filter label=dozo.mount=<dir> --format '{{.Names}}'`）。
- エラーメッセージの文言。
- POD: LIVE CONTAINER の Container Naming と Managing Live Containers に、
  `-I` なしの `dozo -L` / `dozo -K` と、取り違えのエラーを書く。
- テスト: スタブで、1 つ見つかる・複数・なし、`-K`、取り違えのエラー、`-N` では
  確かめないこと、ラベルなしのコンテナ。実機で、`a/proj` と `b/proj` の取り違えが
  エラーになることと、サブディレクトリから `dozo -L` でつながること。
